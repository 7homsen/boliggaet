# Boliggaet – implementation spec

Overview of the app as it is currently built. Updated with every change that adds, removes or changes a page, the navigation or the styling (see `CLAUDE.md`).

## Purpose

Boliggaet is a Flutter app for Android, iOS and web. Its purpose and audience are not described yet.

## Pages

| Page | How it's reached | Purpose | Main actions |
|---|---|---|---|
| Start | App start | The first page the user sees, where they choose what to do. | Two stacked buttons: "Nyt Spil" and "Jeg ser en bolig". Neither does anything yet. |

## Navigation

```
App start → Start
```

There are no other pages yet. The pages behind the two start-page buttons are not built.

## Styling

- **Overall look:** Flutter's default Material 3 look. No custom branding yet.
- **Colours:** generated by Material 3 from a deep purple seed colour. Light theme only; no dark mode.
- **Typography:** Material 3 default text styles and the platform's default font.
- **Components:** standard Material components with default styling. The start page uses filled buttons of equal width, stacked and centred, with a maximum width so they don't stretch on wide screens. No app bar.
